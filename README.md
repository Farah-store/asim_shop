# Asim Shop

Flutter mobile application for Asim Shop.

## Store

https://asim-shop.com

## Features

- WooCommerce products
- Product grid
- User authentication
- WooCommerce orders
- TeraWallet integration
- User account
- Shopping cart
- Custom sidebar
- Mobile bottom navigation
- WhatsApp support
- Font Awesome icons
- Arabic RTL interface
- Noto Kufi Arabic
- Push notifications
